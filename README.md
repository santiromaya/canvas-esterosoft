# Estero Software — Modelo de Negocio Canvas

Sitio web interactivo que presenta el Modelo de Negocio Canvas de **Estero Software**, desarrollado en el marco del **Programa Incubar 2026 · Nodo Tecnológico** de Santiago del Estero, Argentina.

## Demo

[canvas-esterosoft.vercel.app](https://canvas-esterosoft.vercel.app/)

## Características

- 9 bloques del Business Model Canvas interactivos con modal de detalle
- Hero animado con Framer Motion
- Menú hamburguesa para mobile
- Diseño responsive (mobile, tablet y desktop)
- Navbar flotante con efecto glassmorphism

## Stack

- [React 19](https://react.dev/)
- [TanStack Router](https://tanstack.com/router)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [Radix UI](https://www.radix-ui.com/)
- [Lucide Icons](https://lucide.dev/)
- [Vite](https://vite.dev/)

## Instalación

```bash
npm install
npm run dev
```
